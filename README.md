# Catálogo de productos de México (Open Food Facts)

`off_mx.json` es un subconjunto del volcado de [Open Food Facts](https://world.openfoodfacts.org)
con los productos vendidos en México que tienen tabla nutricional. Lo genera cada semana
`.github/workflows/off-catalog.yml` con `tools/build_off_mx.py` y lo usa la app Rutinal para buscar,
escanear y sugerir alternativas sin conexión.
